A simple 2D platformer game featuring Bocchi from *Bocchi The Rock!* anime, built with Pygame.

## Features ✨
- Play as Hitori "Bocchi" Gotoh from Bocchi The Rock!
- Authentic OST from the anime as background music
- Simple yet challenging platformer mechanics
- Score tracking system

## Requirements 🛠️
- Python 3.x
- Pygame library
```

## Installation 📥
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Bocchi-Jumpy-Game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Bocchi-Jumpy-Game
   ```
3. Install the required dependencies:
   ```bash
   pip install pygame
   ```

## How to Play 🎮
- **Spacebar** or **Up Arrow**: Jump
- **Left/Right Arrow Keys**: Move Bocchi
- Avoid obstacles and collect points to increase your score!
